# Retour arrière FoxCat Energy 1.7.3

1. Désactivez la régulation ou utilisez l’interrupteur d’appareil avant de retirer l’intégration.
2. Le dashboard géré par FoxCat est sauvegardé dans `dashboard.yaml.bak` avant chaque changement de version. En cas d’échec de chargement, l’ancien fichier et l’état de version sont restaurés automatiquement.
3. Pour revenir à une version précédente, utilisez « Version du dashboard »; le champ `previous_version` permet aussi le retour via l’action interne de restauration.
4. Pour revenir au moteur 1.7.2, restaurez votre sauvegarde Home Assistant ou installez le paquet 1.7.2. Gardez le Store de FoxCat afin de préserver les réglages.
5. Ne restaurez pas un dashboard FoxCat sur un dashboard personnalisé : conservez d’abord votre copie et restaurez-la manuellement si nécessaire.

Le tag et la release 1.7.3 ne sont pas créés par ce changement.
